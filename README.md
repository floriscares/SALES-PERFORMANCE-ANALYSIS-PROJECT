# Sales Performance Analysis Using Power BI

## Project Overview

This project uses Power BI to analyze sales performance across product categories, regions, and months. The dashboard helps users understand sales revenue, profit, order volume, and product performance through interactive visualizations.

## Project Objectives

* Analyze total sales and total profit.
* Identify the best- and lowest-performing product categories.
* Examine monthly sales trends.
* Compare sales performance across regions.
* Build an interactive dashboard for business reporting.

## Tools and Skills

* Microsoft Power BI
* Power Query for data preparation
* DAX for creating measures
* Data modeling and table relationships
* Data visualization and dashboard design

## Key Performance Indicators (KPIs)

* Total Sales
* Total Profit
* Total Orders
* Total Quantity

## Key Findings

* Body Care recorded the highest sales and profit among the product categories.
* Face Care recorded the lowest sales.
* Home Accessories recorded the lowest profit.
* December recorded the highest monthly sales, while January recorded the lowest.

## Business Recommendations

* Maintain and evaluate strategies supporting the strong performance of Body Care.
* Investigate the sales performance of Face Care to identify potential improvement opportunities.
* Review the costs, discounts, and margins associated with Home Accessories.
* Use monthly sales trends to support inventory planning and promotional decisions.

## Dashboard Features

* Interactive region slicer
* Date-range slicer
* Product category slicer
* KPI cards
* Sales and profit charts

This project demonstrates practical skills in data preparation, data modeling, DAX calculations, interactive dashboard development, and business-focused data analysis.
